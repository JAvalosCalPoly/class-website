In Mathematics, it is common to use \(\LaTeX\) to design conference posters. Usually this is done with a document class called "Beamer" (which is also used to make slideshows) using a package called beamerposter

Download the ZIP file of the CPP poster template along with a .sty file and some image assets. I have modified the Gemini theme and beamerposter to make a standard three-column conference poster in a way that is compatible with CPP brand guidelines.

Open this in Overleaf or the editor of your choice, and put some content in there with at least one block per column. You can move to the next column with \columnbreak.

Optional: Can you add a bibliography using BibTeX or BibLaTeX?
